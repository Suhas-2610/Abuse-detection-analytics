# Abuse Detection Analytics

## Overview
A Python and SQL based analytics project that simulates payment and e-commerce abuse scenarios, performs root cause analysis, and generates automated ranked alert reports — designed to mirror real world abuse prevention workflows in fintech environments.

## Tech Stack
- Python
- PostgreSQL / SQLite
- SQL
- pandas
- Jupyter Notebook

## Features
- Synthetic abuse dataset generation covering promo abuse, refund fraud and account takeover signals
- Layered SQL queries for root cause analysis including cohort breakdowns and velocity anomalies
- Correlation analysis across device, IP and behavioural flags
- Ranked high risk user alert output with reason codes
- Documented problem statement, analysis approach, findings and recommendations
